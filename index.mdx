Read trader grades, whale trades, sharp-money flow, positions, and insider-radar flags from Polymarket and Kalshi. Use the API when a bot, an agent, or a research tool needs graded trader context instead of raw market prints.

## Choose an interface

- **REST API** at `https://api.0xinsider.com/api/v1/` for bots, dashboards, and research code.
- **Local MCP server** [`@0xinsider/mcp`](https://www.npmjs.com/package/@0xinsider/mcp) over stdio for Claude Code, Cursor, Codex, and Gemini CLI.
- **Remote MCP** at `POST /api/v1/mcp` over Streamable HTTP for agents that cannot run a local process.

All three use the same API key, the same read-only tool catalog, and the same rate limits. One [Pro subscription](https://0xinsider.com/pricing) covers all three.

<Tip>
  Give an AI agent [llms-full.txt](https://0xinsider.com/llms-full.txt) or [agents.md](https://0xinsider.com/agents.md). Each file holds the full API contract.
</Tip>

## Know what the API adds

Polymarket and Kalshi expose raw trades. 0xinsider adds trader grades, signal scores, sharp-money flow, position timelines, and pattern detection. Kalshi public prints stay anonymous, so grade and P&L fields can be null for them.

Use the API to answer questions such as:

- Which traders have a strong record in a category?
- Did a high-grade trader buy this market recently?
- Is a trader building a position before resolution?
- Which markets receive sharp-money flow?
- What fill price appears in a trader's timeline?

## Make a first request

Read the top leaderboard entry:

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/leaderboard?limit=1"
```

The response uses the list envelope. Field names match the `LeaderboardEntry` schema. The values below are illustrative.

```json
{
  "object": "list",
  "data": [
    {
      "id": "trd_0x863134d00841b2e200492805a01e1e2f5defaa53",
      "address": "0x863134d00841b2e200492805a01e1e2f5defaa53",
      "username": "RepTrump",
      "grade": "S",
      "streak_tier": "hot",
      "score": 97.94,
      "pnl": 7532409.67,
      "win_rate": 1.0,
      "markets_traded": 28,
      "strategy_type": "swing_trader",
      "platform": "polymarket"
    }
  ],
  "has_more": true,
  "next_cursor": "<opaque cursor>",
  "meta": {
    "request_id": "req_example",
    "cached": false,
    "cost": 1,
    "ranking_generation": 42,
    "ranking_as_of": "2026-08-25T05:00:00Z"
  }
}
```

Pass `next_cursor` as `cursor` to read the next page. See [Pagination](/concepts/pagination).
