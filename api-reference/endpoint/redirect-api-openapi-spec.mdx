Resolve the canonical OpenAPI document from the API origin. Use it in code generation or docs tools that start from `api.0xinsider.com`.

## Read the redirect

- The response is `307` with `Location: https://0xinsider.com/api/v1/openapi.json`. The web origin owns the document.
- No key is needed.
- Follow the redirect with `curl -L`, or read `Location` and fetch that URL.

```bash
curl -I "https://api.0xinsider.com/api/v1/openapi.json"
```
