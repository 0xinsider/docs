---
title: "Get Leaderboard"
openapi: "GET /api/v1/leaderboard"
---

List ranked traders with grades S, A, and B, sorted by score. Use it to build a follow list before you request full profiles.

## Read the ranking

- Each row has `id`, `address`, `username`, `grade`, `score`, `streak_tier`, `pnl`, `realized_pnl`, `volume`, `markets_traded`, `win_rate`, `strategy_type`, `platform`, and `last_active`.
- `realized_pnl` is banked P&L and matches the grade. `pnl` includes unrealized open positions and stays for back-compat.
- `strategy_type` is nullable. `strategy` filters on one of `accumulator`, `algo_trader`, `arbitrageur`, `directional`, `event_driven`, `market_maker`, `momentum`, `scalper`, `speculator`, `swing_trader`. Any other value returns `400`.
- `category` matches canonical buckets. Political variants fold into `Politics`, and mapped buckets ignore case. Passthrough categories such as `Crypto` and `NBA` are case-sensitive.
- `meta.ranking_generation` and `meta.ranking_as_of` identify the committed ranking behind the page.
- `limit` is 1 to 100, default 20. `next_cursor` is an opaque `lbv1_` cursor bound to the generation and the filters.

## Handle cursor_expired

1. A `400` with `error.reason: "cursor_expired"` means the ranking generation or the filters changed since the cursor was issued.
2. Discard the rows you hold.
3. Request page one again without `cursor`, then walk forward with the new `next_cursor`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/leaderboard?category=Crypto&limit=20"
```

## Cache the ranking

The response carries an `ETag` that includes the ranking generation. Send it as `If-None-Match` to get `304 Not Modified` until a new generation commits.
