---
title: "List Large Positions"
openapi: "GET /api/v1/large-positions"
---

List the largest open positions held by graded traders, largest value first. Use it for a market board or a risk review.

## Read the positions

- `min_size` is a USD floor. `min_grade` is an allowlist: `B` matches S, A, and B. `condition_id` accepts the raw provider value or the `mkt_`-prefixed market id.
- `category` is one CSV record of exact category values and ignores case. `NBA,WNBA` is valid. Quote a value that contains a comma.
- The scanner covers Polymarket only. A Kalshi or unknown `condition_id` returns an empty list, never fabricated rows.
- `total_size_usd` is the provider current value of the leg. `position_unrealized_pnl` is the provider per-position unrealized P&L.
- `event_leg_count` is the number of legs from the same event collapsed into the row. `event_total_value_usd` sums them and equals `total_size_usd` when the count is 1.
- `trader.pnl` is lifetime realized P&L. `current_price` is the latest provider mark.
- An API key gets the full list. The teaser cap of the product UI does not apply.
- `limit` is 1 to 100, default 20. `next_cursor` is absent on the last page.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/large-positions?min_grade=A&min_size=25000&limit=50"
```

## Cache the list

The response carries an `ETag`. Send it as `If-None-Match` to get `304 Not Modified` when the list is unchanged.
