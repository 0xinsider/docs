title: "Get Stream"
openapi: "GET /api/v1/stream"

Open a resumable Server-Sent Events stream of live feed envelopes. Use this endpoint when a service needs whale-trade and feed events with low delay.

## Read the frames

- Each data frame has an SSE `id` equal to the envelope `seq`. The envelope also carries `published_at` and `type`.
- `seq` comes from one cluster-shared sequence. It stays valid across replicas and restarts.
- An idle stream sends a `: keep-alive` comment line every 5 seconds.
- `event: resync` marks a cursor outside the retained window or a gap in live delivery. Refetch current state, then keep the connection.
- `event`, `condition_id`, and `min_grade` filter the stream at connect time. An unknown value returns `400`.

```bash
curl -N -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Last-Event-ID: $LAST_SEQ" \
  "https://api.0xinsider.com/api/v1/stream"
```

## Reconnect with Last-Event-ID

1. Store the `id` of each frame after you process it.
2. On reconnect, send that value in the `Last-Event-ID` header. Browser `EventSource` sends it for you.
3. Use `?last_event_id=` or `?seq=` when you cannot set the header.
4. Read the replayed frames, then the live frames. An absent or non-numeric value attaches live with no replay.

## Handle the 429 and 503

- `429` means the per-key or cluster-wide connection cap is full. Wait for `Retry-After` seconds, then reconnect.
- `503` means the admission store is unavailable. Wait for `Retry-After` seconds, then reconnect.
- Close idle streams to free a slot.
