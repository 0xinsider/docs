---
title: "Get Trader P&L"
openapi: "GET /api/v1/trader/{address}/pnl"
---

Get a trader's daily P&L series with period stats, monthly totals, yearly totals, and drawdown. Use it to draw an equity curve or to compare fixed periods.

## Read the series

- `address` accepts a `0x...` wallet address, a username, or a `trd_`-prefixed trader ID.
- `entries` is oldest first. Each point has `date` and `daily_change`, plus nullable `cumulative_profit`, `total_pnl`, `markets_traded`, and `total_volume`.
- `stats` has `all`, `d90`, `d30`, and `d7`. Each period carries `current`, `change`, `change_pct`, `best_day`, `worst_day`, `win_days`, `loss_days`, `avg_day`, and `rebase_anchor`.
- `monthly` and `year_totals` aggregate per month and per year. `drawdown` is the underwater series.
- `freshness_at` is when the `daily_pnl` read model was last rebuilt for this trader. It is `null` when it was never rebuilt.
- The series comes from the precomputed read model, not a per-request replay. It spans both providers where the read model has data.
- A known trader with no daily P&L returns `200` with empty arrays. An unknown address returns `404`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/0x863134d00841b2e200492805a01e1e2f5defaa53/pnl"
```

## Cache the series

The response carries an `ETag`. Send it as `If-None-Match` to get `304 Not Modified` when the series is unchanged.
