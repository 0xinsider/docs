---
title: "Get Insider Radar"
openapi: "GET /api/v1/insider-radar"
---

List heuristic flags for suspicious trade patterns: pre-resolution accumulation and coordinated wallets. Use this endpoint to build a review queue.

## Read the flags

- `suspicion_score` is 0 to 100. `severity` is `flag` or `watch`.
- The order is highest suspicion first. The cursor is a composite of `suspicion_score` and `id`.
- `scores.timing`, `scores.edge`, `scores.size`, and `scores.fresh_wallet` are the recorded component scores. Each is nullable and fixed at detection time.
- `evidence` is structured JSON with the detection detail.
- `trader.id` is the `trd_` ID and `market.id` is the `mkt_` ID. Both objects also carry the raw `address` or `condition_id`.
- A high score marks a review target. It does not prove insider activity.

## Filter the queue

- `min_suspicion` is 0 to 100 with a default of 0. A value outside that range returns `400`.
- `severity` accepts `flag` or `watch`.
- `limit` is 1 to 100 with a default of 20.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/insider-radar?min_suspicion=60&severity=flag&limit=20"
```

## Cache the list

The 200 response carries an `ETag`. Send `If-None-Match` to get `304 Not Modified` with an empty body when nothing changed.
