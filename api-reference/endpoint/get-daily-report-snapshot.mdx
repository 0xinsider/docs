---
title: "Get Daily Report Snapshot"
openapi: "GET /api/v1/reports/daily"
---

Get the whale-activity report for one UTC date. Use this endpoint for a daily email, a Slack brief, or a "what happened yesterday" panel.

## Read the report

- `date` is required, in `YYYY-MM-DD`.
- `report.total_whale_trades`, `total_whale_volume`, `biggest_trade_size`, and `active_traders` describe the date.
- `report.top_whale_trades` holds at most 50 rows.
- `snapshot.status` is `final` for a past date and `rolling` for today.
- `completeness.status` is `complete`, `partial`, or `empty`. A date with no whale rows returns `200` with `empty`.
- `snapshot.version` never changes for a closed period. A rolling period can get a new version after each refresh. Use it as a cache key.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/reports/daily?date=2026-05-08"
```
