Get the API entry document without a key: the base URL, docs URL, OpenAPI URL, health URL, and the complete authenticated route index. Use it as the first request of an SDK or an agent.

## Read the document

- `api_base_url` is the API origin for V1 requests. `health_url` is the unauthenticated health check.
- `docs_url` is the agent-readable reference. `openapi_url` is the OpenAPI document on the web origin.
- `authentication` states which routes are public and which need a key.
- `authenticated_routes` lists every authenticated route as `<METHOD> <path>`. It is the whole surface, not a sample. Copy a path from it instead of a guess.
- The index is a hand-maintained list, and no automated check compares it with the spec. When they disagree, the document at `openapi_url` wins.

```bash
curl "https://api.0xinsider.com/api/v1"
```
