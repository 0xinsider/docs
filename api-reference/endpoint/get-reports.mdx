---
title: "Get Reports"
openapi: "GET /api/v1/reports"
---

Get a daily, weekly, or monthly report snapshot from one route. Use this endpoint when a report picker lets a user change the time range.

## Choose the period

- `granularity` is `daily`, `weekly`, or `monthly`. Any other value returns `400`.
- `daily` takes a UTC date, `YYYY-MM-DD`.
- `weekly` takes an ISO week, `YYYY-WW`, or a `from,to` pair of `YYYY-MM-DD` dates.
- `monthly` takes a calendar month, `YYYY-MM`.
- The body matches the single-period route for the same period. Only `meta.request_id` differs.
- `report.top_whale_trades` holds at most 50 rows for daily, 100 for weekly, and 200 for monthly.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/reports?granularity=daily&period=2026-05-08"
```

## Read the snapshot state

- `snapshot.status` is `final` when the range ended before today. Otherwise it is `rolling` and `snapshot.mutable_until` names the last date.
- `completeness.status` is `complete`, `partial`, or `empty`. An empty range returns `200` with `empty`, not `404`.
- `report.total_whale_volume` sums local whale-alert activity. It is not provider lifetime volume.
