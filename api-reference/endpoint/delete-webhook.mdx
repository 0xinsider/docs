---
title: "Delete Webhook"
openapi: "DELETE /api/v1/webhooks/{id}"
---

Remove a webhook endpoint. The API stops deliveries to it at once.

## Delete the endpoint

- The response returns the endpoint with `status: "disabled"`.
- [List Webhooks](/api-reference/endpoint/list-webhooks) omits the endpoint. [Get Webhook](/api-reference/endpoint/get-webhook) returns `404` for its `id`.
- Every queued delivery moves to `dead_letter`.
- Deletion is permanent. Create a new endpoint to resume.

```bash
curl -X DELETE \
  -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Idempotency-Key: webhook-delete-2026-06-01" \
  "https://api.0xinsider.com/api/v1/webhooks/42"
```

## Handle the Idempotency-Key 409

1. On `409` with `error.reason="idempotency_in_progress"`, keep the same key.
2. Wait a few seconds, then send the same request again.

## Related
