---
title: "Get Platforms"
openapi: "GET /api/v1/platforms"
---

Get the capability matrix: which V1 surfaces each provider supports. Use it at client startup to hide a feature a provider does not support. No key is needed.

## Read the matrix

- `platforms.polymarket` and `platforms.kalshi` each carry `grade`, `pnl`, `strategy`, `timeline`, `whale_signal`, `insider_radar`, and `market_snapshot`.
- Each value is `supported`, `partial`, or `unsupported`.
- Polymarket is `supported` on every surface today. Kalshi is `partial` on `pnl`, `timeline`, and `market_snapshot`, and `unsupported` on the rest.
- The matrix is static backend metadata. The endpoint does not call a provider at request time.
- Read the matrix at startup instead of a hard-coded coverage table.

```bash
curl "https://api.0xinsider.com/api/v1/platforms"
```
