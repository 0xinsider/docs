---
title: "Get Usage"
openapi: "GET /api/v1/usage"
---

Read the current request budget. The read itself is free. Use this endpoint before a polling loop or a batch job.

## Read the budget

- `rate_limit.used`, `limit`, and `remaining` describe the 60-second sliding window. `window_seconds` is `60`.
- `rate_limit.reset_at` is the Unix time of the next window boundary.
- `daily_usage.used` counts requests since UTC midnight. It excludes calls to this endpoint.
- `daily_usage.limit` and `remaining` are `null`. V1 has no daily cap, so do not infer one.
- `daily_usage.reset_at` is the next UTC midnight. `window_seconds` is `86400`.
- This read does not count against `rate_limit` or `daily_usage`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/usage"
```

## Handle the 429

This endpoint has its own guard of 100 reads per minute.

1. Read `Retry-After` from the `429` response.
2. Wait that many seconds.
3. Send one request. Do not poll this endpoint in a tight loop.
