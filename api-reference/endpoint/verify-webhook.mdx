---
title: "Verify Webhook"
openapi: "POST /api/v1/webhooks/{id}/verify"
---

Activate a webhook endpoint with its one-time `verification_token`. Call this endpoint after [Create Webhook](/api-reference/endpoint/create-webhook) or after a URL change.

## Verify the endpoint

- The token comes from `verification.token` on create or on a URL change. It expires after 24 hours.
- Success sets `status` to `active`, sets `verified_at`, and resets `failure_count` to 0.
- The call sends no test delivery to your endpoint.

```bash
curl -X POST \
  -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"verification_token": "whv_3c2e...redacted"}' \
  "https://api.0xinsider.com/api/v1/webhooks/42/verify"
```

## Handle the 400

An invalid or expired token returns `400` with `error.param="verification_token"`.

1. Delete the endpoint with [Delete Webhook](/api-reference/endpoint/delete-webhook).
2. Create it again to get a new token and a new signing secret.
3. Send the new token within 24 hours.
