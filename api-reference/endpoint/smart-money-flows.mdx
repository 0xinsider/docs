Deprecated alias of [Sharp Money Flows](/api-reference/endpoint/sharp-money-flows). The route stays live and returns the same bytes. Use Sharp Money Flows for a new integration.

## Read the alias

- The parameters, the payload, and the `ETag` are the same as Sharp Money Flows. Both paths run one handler.
- Each row carries `sharp_money` (canonical) and `smart_money` (deprecated, identical).
- The response has no `Deprecation` or `Sunset` header. This page is the only notice.
- Remote MCP exposes the route as `get_smart_money_flows` next to the canonical `get_sharp_money_flows`.

## Migrate to the canonical route

1. Replace the path with `/api/v1/markets/sharp-money-flows`.
2. Read `sharp_money` instead of `smart_money`.
3. Keep every query parameter. The names and values are identical.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/markets/smart-money-flows?timeframe=7d&min_grade=B&limit=10"
```
