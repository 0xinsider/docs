---
title: "List Webhooks"
openapi: "GET /api/v1/webhooks"
---

List the webhook endpoints on your account. Use this endpoint for a settings page or a startup check.

## Read the list

- `data` holds `webhook` objects, newest first. Deleted endpoints are omitted.
- `status` is `pending_verification`, `active`, or `disabled`.
- `failure_count` counts consecutive failed delivery attempts. One success resets it to 0.
- `retry_policy.max_attempts` is `8` and `retry_policy.terminal_status` is `dead_letter`.
- `signing_secret` and `verification` never appear here. They appear only on create, rotate-secret, and a URL change.
- The list has one page. `has_more` is `false` and `next_cursor` is `null`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/webhooks"
```
