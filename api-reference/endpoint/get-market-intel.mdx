---
title: "Get Market Intel"
openapi: "GET /api/v1/market/{condition_id}/intel"
---

Get the sharp-money flow for one market over a lookback window. Use this endpoint after search or explore returns a market ID.

## Read the intel

- `sharp_money.direction` is `YES` or `NO`. It names the side with more graded flow in the window.
- `sharp_money.net_flow_usd`, `buy_volume_usd`, `sell_volume_usd`, and `whale_trade_count` cover the `timeframe` window only.
- `sharp_money.top_positions` items carry `address`, `username`, `grade`, `side`, `token_id`, and `size_usd`.
- `sharp_money.token_id` is the Polymarket CLOB token ID for the direction outcome. It is null for Kalshi and unsynced markets.
- `smart_money` is a deprecated byte-identical alias of `sharp_money`. Read `sharp_money`.
- `timeframe` accepts `1h`, `4h`, `24h` (default), and `7d`. An unknown value returns `400`.
- `meta.cached` and `meta.cache_age_s` describe the response cache: 60 seconds for `1h`, 300 seconds for the other windows.

## Handle the market ID

1. Pass the raw `condition_id` from search or explore, or the `mkt_` market ID from any V1 response.
2. A `trd_`, `wt_`, or `rf_` prefix returns `400 bad_request` with `error.param="condition_id"`.
3. An unknown market returns `404 not_found`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/market/0x123.../intel?timeframe=24h"
```

## Cache the intel

The 200 response carries an `ETag`. Send `If-None-Match` to get `304 Not Modified` with an empty body when nothing changed.
