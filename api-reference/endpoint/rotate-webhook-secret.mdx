---
title: "Rotate Webhook Secret"
openapi: "POST /api/v1/webhooks/{id}/rotate-secret"
---

Create a new signing secret for a webhook endpoint. Use this endpoint after a leak or on a rotation schedule.

## Rotate the secret

- The response shows the new `signing_secret` once. Store it now.
- The old secret stops when the call returns. There is no overlap window.
- `failure_count` resets to 0.
- A delivery that fails your signature check retries after 1 minute with the new secret. Deploy the new secret within that delay.

```bash
curl -X POST \
  -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Idempotency-Key: webhook-rotate-2026-06-01" \
  "https://api.0xinsider.com/api/v1/webhooks/42/rotate-secret"
```

## Handle the 409

Branch on `error.reason`.

1. `webhook_delivery_in_progress`: one delivery is in flight. Retry after that request completes.
2. `idempotency_in_progress`: the same rotation is still in progress. Retry with the same key.
3. A replay with the same key returns the same one-time secret. Do not log the response.
