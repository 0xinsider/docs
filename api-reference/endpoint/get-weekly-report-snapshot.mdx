---
title: "Get Weekly Report Snapshot"
openapi: "GET /api/v1/reports/weekly"
---

Get the whale-activity report for one ISO week or one date range. Use this endpoint for a weekly email, a dashboard, or a research review.

## Choose the range

- `week` takes an ISO week in `YYYY-WW`. The range runs Monday to Sunday.
- `from` and `to` take a `YYYY-MM-DD` pair. Send both or neither.
- A request with neither form returns `400` with `error.param="from"`.
- `report.top_whale_trades` holds at most 100 rows.
- `snapshot.status` is `final` when the range ended before today. Otherwise it is `rolling` and can still change.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/reports/weekly?week=2026-19"
```
