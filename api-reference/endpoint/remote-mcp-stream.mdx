Open the optional server-to-client stream for a [Remote MCP](/api-reference/endpoint/remote-mcp) session. Use it only when your MCP client requires the GET stream. Every request and every tool result flows over POST.

## Read the stream

- The response is `200` with `Content-Type: text/event-stream` and `Cache-Control: no-cache`.
- The server sends no notifications today. The body opens with one SSE comment line and then stays silent until you close it.
- Send `Mcp-Session-Id` from `initialize`. The server echoes it on the response.
- Auth matches POST: `Authorization: Bearer <key>`, with `?token=` as the deprecated path.
- When the request carries an `Origin` header, it must match the 0xinsider allowlist or localhost. A rejected `Origin` returns `403` with JSON-RPC code `-32000`.
- A tool result never arrives on this stream. Read it from the POST response.

```bash
curl -N \
  -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  "https://api.0xinsider.com/api/v1/mcp"
```
