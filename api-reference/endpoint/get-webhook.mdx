---
title: "Get Webhook"
openapi: "GET /api/v1/webhooks/{id}"
---

Get one webhook endpoint by its integer `id`. Use this endpoint to show status on an account page or to check the URL before an update.

## Read the webhook

- `status` is `pending_verification`, `active`, or `disabled`.
- `verified_at` is `null` until the endpoint passes verification.
- `verification_token_expires_at` shows when the current token expires.
- `failure_count` counts consecutive failed delivery attempts. A count of 8 disables the endpoint.
- `signing_secret` never appears here. Store it on create or rotate-secret.
- An unknown or deleted `id` returns `404`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/webhooks/42"
```
