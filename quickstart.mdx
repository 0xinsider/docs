Create an API key, test it, then follow high-grade traders with four requests. Use this page when you start a new integration.

## Create a key

API access needs an active [Pro subscription](https://0xinsider.com/pricing).

<Steps>
  <Step title="Sign up or log in">
    Open [0xinsider.com/sign-up](https://0xinsider.com/sign-up).
  </Step>
  <Step title="Subscribe to Pro">
    Choose a Pro billing period on [Pricing](https://0xinsider.com/pricing).
  </Step>
  <Step title="Generate the key">
    Open [Developers](https://0xinsider.com/developers) and click **Generate token**. The page shows the full key once. Copy it now.
  </Step>
</Steps>

A key starts with `oxi_sk_live_` and continues with 64 hex characters.

<Tip>
  Store the key in an environment variable:
  ```bash
  export OXINSIDER_API_KEY="oxi_sk_live_..."
  ```
</Tip>

## Test the key

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  https://api.0xinsider.com/api/v1/usage
```

```json
{
  "object": "usage",
  "data": {
    "rate_limit": {
      "used": 7,
      "limit": 100,
      "remaining": 93,
      "reset_at": 1710772860,
      "window_seconds": 60
    },
    "daily_usage": {
      "used": 42,
      "limit": null,
      "remaining": null,
      "reset_at": 1710806400,
      "window_seconds": 86400
    }
  },
  "meta": { "request_id": "req_example", "cached": false, "cost": 1 }
}
```

- A `200` response means the key and the subscription are active.
- This route does not spend the 100-request budget. It has its own guard of 100 reads per minute.
- `daily_usage.limit` and `daily_usage.remaining` are `null` because V1 has no daily cap.

## Follow high-grade traders

Use four calls in order: leaderboard, trader profile, whale trades, market intel.

<Steps>
  <Step title="Read five leaderboard entries">
    ```bash
    curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
      "https://api.0xinsider.com/api/v1/leaderboard?limit=5"
    ```
    Each item carries `id`, `grade`, `score`, `pnl`, and `strategy_type`. Keep the `id` values you want to inspect.
  </Step>
  <Step title="Read one trader profile">
    The path accepts a wallet address, a known username, or a `trd_` ID:
    ```bash
    curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
      "https://api.0xinsider.com/api/v1/trader/0x863134d00841b2e200492805a01e1e2f5defaa53"
    ```
    The response carries `grade`, `pnl`, `stats.win_rate`, `strategy`, and `category_strengths`. Add `expand=quant_metrics` or `expand=trust` for heavy fields.
  </Step>
  <Step title="Read recent high-grade trades">
    Read 50 recent trades from A-grade or better traders:
    ```bash
    curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
      "https://api.0xinsider.com/api/v1/whale-trades?min_grade=A&limit=50"
    ```
    Add `category` and `min_size` for a narrower feed:
    ```bash
    curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
      "https://api.0xinsider.com/api/v1/whale-trades?min_grade=A&category=crypto&min_size=10000&limit=50"
    ```
  </Step>
  <Step title="Read one market">
    Take `market.condition_id` from a trade. The path also accepts the `mkt_` ID from `market.id`:
    ```bash
    curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
      "https://api.0xinsider.com/api/v1/market/<condition_id>/intel"
    ```
    `sharp_money` carries `direction`, `net_flow_usd`, `buy_volume_usd`, `sell_volume_usd`, and `top_positions`.
  </Step>
</Steps>

Run this loop in a cron job, a chatbot, or a dashboard.

## Run the loop in code

<CodeGroup>
```javascript JavaScript
const headers = { Authorization: `Bearer ${process.env.OXINSIDER_API_KEY}` };
const BASE = "https://api.0xinsider.com/api/v1";

const top = await fetch(`${BASE}/leaderboard?limit=5`, { headers }).then(r => r.json());
const topId = top.data[0].id;

const trader = await fetch(`${BASE}/trader/${topId}`, { headers }).then(r => r.json());
const whales = await fetch(`${BASE}/whale-trades?min_grade=A&limit=50`, { headers }).then(r => r.json());

console.log({ top: top.data[0], grade: trader.data.grade, whales: whales.data.length });
```

```python Python
import os, requests

H = {"Authorization": f"Bearer {os.environ['OXINSIDER_API_KEY']}"}
BASE = "https://api.0xinsider.com/api/v1"

top = requests.get(f"{BASE}/leaderboard", params={"limit": 5}, headers=H).json()
top_id = top["data"][0]["id"]

trader = requests.get(f"{BASE}/trader/{top_id}", headers=H).json()
whales = requests.get(
    f"{BASE}/whale-trades",
    params={"min_grade": "A", "limit": 50},
    headers=H,
).json()

print(top["data"][0], trader["data"]["grade"], len(whales["data"]))
```
</CodeGroup>

## Batch known traders

If you already hold addresses or usernames, read up to 25 profiles in one call:

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"traders": ["swisstony", "0x0000000000000000000000000000000000000000"], "expand": ["strategy"]}' \
  "https://api.0xinsider.com/api/v1/traders/batch"
```

- Each item returns `status` as `ok` or `error`. One bad input does not fail the other items.
- Each requested item costs one batch item unit from a separate budget. See [Rate Limits](/rate-limits).

<Tip>
  Browser apps can call `/api/v1/*` from any origin with the `Authorization` header. Do not send cookies. See [Browser CORS](/api-reference/introduction#browser-cors).
</Tip>
