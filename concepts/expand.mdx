---
title: "Expanding Responses"
description: "Request strategy, categories, quant_metrics, or trust fields with the expand parameter."
---

`expand` adds heavy fields to a trader or market snapshot response. Use it only for the fields your screen reads, because an expanded request skips the response cache.

## Pass the parameter

The parser accepts three forms. Mix them freely.

```bash
# Comma-separated
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/swisstony?expand=strategy,categories"

# Repeated key
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/swisstony?expand=strategy&expand=trust"

# Bracket alias
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/swisstony?expand[]=strategy&expand[]=trust"
```

- An unknown value is ignored.
- A malformed percent-encoded value returns `400` with `error.param="expand"`.
- A field you did not expand is absent from the response, not `null`.

## Choose a trader expand value

These values work on [`GET /api/v1/trader/{address}`](/api-reference/endpoint/get-trader) and [`POST /api/v1/traders/batch`](/api-reference/endpoint/batch-get-traders):

| Value | Adds field | Content |
|---|---|---|
| `strategy` | `strategy` | `strategy_type`, a nullable `description`, and `confidence`, which is always `null`. See [Strategy types](/concepts/strategy-types). |
| `categories` | `category_strengths` | An object keyed by category. Each value carries `rank`, `total_in_category`, `total_pnl`, `n_markets`, `wins`, `losses`, and `win_rate`. |
| `quant_metrics` | `quant_metrics` | Nine risk and performance numbers, present only when the computed row is under six hours old. See [Quant metrics](/concepts/quant-metrics). |
| `trust` | `trust` | Source, freshness, reconciliation, and completeness for 17 fields. See [Trust metadata](/concepts/trust-metadata). |

`strategy` runs 16 parallel queries and adds about 200 ms.

```json
{
  "object": "trader",
  "data": {
    "id": "trd_0x204f72f35326db932158cba6adff0b9a1da95e14",
    "username": "swisstony",
    "grade": "S",
    "strategy": {
      "strategy_type": "swing_trader",
      "description": null,
      "confidence": null
    }
  }
}
```

## Expand a batch

The batch body carries one `expand` array for every trader. Supply 1 to 25 traders.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  -X POST "https://api.0xinsider.com/api/v1/traders/batch" \
  -H "Content-Type: application/json" \
  -d '{"traders": ["swisstony", "0x0000000000000000000000000000000000000000"], "expand": ["strategy"]}'
```

Use the batch for many traders instead of one expanded request per trader.

## Expand a market snapshot

[`GET /api/v1/market/{condition_id}/snapshot`](/api-reference/endpoint/get-market-snapshot) accepts `expand=trust` only. It adds `trust.current_price` and `trust.spread_bps`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/market/0x123.../snapshot?expand=trust"
```
