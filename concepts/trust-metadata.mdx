---
title: "Trust Metadata"
description: "Read the source, freshness, reconciliation, and completeness of each API value."
---

Trust metadata is a per-field object with four facts: the source of a value, its age, its match with provider data, and its completeness. Request it before an automated action depends on one number.

## Request it

Pass `expand=trust`. Without it, the `trust` block is absent.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/swisstony?expand=trust"
```

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/market/0x123.../snapshot?expand=trust"
```

- [`GET /api/v1/trader/{address}`](/api-reference/endpoint/get-trader) and [`POST /api/v1/traders/batch`](/api-reference/endpoint/batch-get-traders) return `trust` with 17 keys: `total_pnl`, `realized_pnl`, `unrealized_pnl`, `markets_traded`, `win_rate`, `daily_win_rate`, `total_volume`, `grade`, `score`, `rank`, `streak_tier`, `strategy`, `category_strengths`, `quant_metrics`, `last_active`, `synced_at`, `sync_status`.
- [`GET /api/v1/market/{condition_id}/snapshot`](/api-reference/endpoint/get-market-snapshot) returns `trust` with two keys: `current_price` and `spread_bps`.

## Read the shape

```json
{
  "trust": {
    "total_pnl": {
      "source": { "kind": "provider", "owner": "traders", "field": "total_pnl" },
      "freshness": { "status": "fresh", "as_of": "2026-08-28T14:28:20Z", "max_age_s": null },
      "reconciliation": { "status": "provider_backed", "detail": null },
      "completeness": { "status": "complete", "detail": null }
    },
    "grade": {
      "source": { "kind": "computed", "owner": "0xinsider_trader_read_model", "field": "grade" },
      "freshness": { "status": "unknown", "as_of": null, "max_age_s": null },
      "reconciliation": { "status": "computed", "detail": "derived from stored provider-backed trader, position, and market facts" },
      "completeness": { "status": "complete", "detail": null }
    },
    "strategy": {
      "source": { "kind": "computed", "owner": "0xinsider_trader_read_model", "field": "strategy" },
      "freshness": { "status": "unknown", "as_of": null, "max_age_s": null },
      "reconciliation": { "status": "not_applicable", "detail": "request did not expand this derived profile field" },
      "completeness": { "status": "not_computed", "detail": "request did not expand this derived profile field" }
    }
  }
}
```

`owner` names the provider, table, read model, or service that owns the value. `field` names the provider field or column.

## Read `source.kind`

| Value | Meaning |
|---|---|
| `provider` | Copied from a Polymarket or Kalshi value. |
| `database` | Mirrored from a stored row. |
| `cache` | Served from a short-lived cache. |
| `computed` | Derived by 0xinsider from stored facts. |
| `client_input` | Echoed from your request. |
| `unavailable` | No source could supply the field. |

## Read `freshness.status`

| Value | Meaning |
|---|---|
| `fresh` | Inside its age window. |
| `refreshing` | A newer value is on its way. |
| `stale` | Past its age window. |
| `not_live` | A point-in-time value that does not update. |
| `unknown` | No freshness clock exists for the value. |
| `unavailable` | The value itself is unavailable. |

- `as_of` is the instant the value was last known good.
- `max_age_s` is the window after which `fresh` becomes `stale`.
- Computed fields such as `grade`, `score`, and `quant_metrics` report `unknown`. Do not require `fresh` on them.

## Read `reconciliation.status`

| Value | Meaning |
|---|---|
| `provider_backed` | Matches a provider value. |
| `db_mirror` | Mirrored from an earlier provider read, not re-read on this request. |
| `computed` | Derived locally, with no single provider field to compare. |
| `partial` | Compared against some sources, not all. |
| `not_applicable` | Reconciliation does not apply to the field. |
| `unavailable` | No comparison was possible. |

## Read `completeness.status`

| Value | Meaning |
|---|---|
| `complete` | Covers the full contract of the field. |
| `partial` | Covers a subset, such as a fallback value or an in-progress sync. |
| `not_computed` | Not computed on this request, for example a field you did not expand. |
| `not_applicable` | Completeness does not apply. |
| `unavailable` | Could not be determined. |

`detail` carries a short note when a status needs one, for example why a value is `partial`.

## Gate an automated action

1. Reject `source.kind = "unavailable"`.
2. Reject `completeness.status = "partial"` or `"unavailable"`.
3. For `provider` and `database` values, require `freshness.status = "fresh"`.
4. For `computed` values, accept `freshness.status = "unknown"`.

Do not replace an `unavailable` value with `0`, `[]`, or `{}`. Show that the value is unavailable.
