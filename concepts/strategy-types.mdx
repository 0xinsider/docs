`strategy_type` is one of ten labels that describe how a Polymarket trader trades. Use it to filter and compare traders, not to predict results.

## Read the ten labels

A decision tree tests the trader's fill history in this order and stops at the first match:

| `strategy_type` | Rule that assigns it |
|---|---|
| `arbitrageur` | Holds both sides in many markets at a measured pair cost below parity. |
| `market_maker` | Trades both YES and NO in over 40 percent of markets, with over 45 percent of fills on a whole cent. A high-frequency route with the same whole-cent pattern also matches. |
| `event_driven` | Concentrates capital and market type in a small set of markets. |
| `accumulator` | Buys large average sizes with many trades per market and a high win rate, or holds paired both-side positions over a long span. |
| `scalper` | Under half of fills on a whole cent, with short first-to-last spans. |
| `algo_trader` | High frequency, half or more of fills on a whole cent, and neither market-maker rule. |
| `swing_trader` | Mid-range average hold time, fewer markets, and few trades per market. |
| `momentum` | Consistent edge, a positive alpha t-statistic, and a positive scalability slope. |
| `directional` | Fallback when no rule above matches. |
| `speculator` | Reclassification after the tree: a statistically significant loser with no consistent edge. `arbitrageur` and `accumulator` are exempt. |

Whole-cent fill share is a price pattern, not an order-type count. The rules do not establish intent.

## Request the label on a trader

Pass `expand=strategy` to [`GET /api/v1/trader/{address}`](/api-reference/endpoint/get-trader) or [`POST /api/v1/traders/batch`](/api-reference/endpoint/batch-get-traders):

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/trader/swisstony?expand=strategy"
```

```json
{
  "strategy": {
    "strategy_type": "swing_trader",
    "description": "Directional trader",
    "confidence": null
  }
}
```

- `strategy_type` is the label.
- `description` is a stored text and can be `null`.
- `confidence` is always `null` on this API.
- The `strategy` object is absent when you did not expand it or no classification exists.

## Filter the leaderboard

Pass `strategy` to [`GET /api/v1/leaderboard`](/api-reference/endpoint/get-leaderboard). A value outside the ten labels returns `400` with `error.param="strategy"`.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/leaderboard?strategy=arbitrageur&limit=20"
```

Each leaderboard entry carries `strategy_type` without an expand. It is `null` when no classification exists.

## Handle a null label

A trader with too little history has no label. Keep the trader unless your workflow needs the label. Do not map `null` to `directional`.

Classification is Polymarket-only. The [platform matrix](/concepts/platforms) reports `strategy: "unsupported"` for Kalshi.
