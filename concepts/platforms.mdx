0xinsider covers Polymarket and Kalshi. Coverage differs because grades, strategy, and whale signals need wallet-attributed Polymarket data, and Kalshi prints are anonymous.

## Use the platform values

- `polymarket`
- `kalshi`
- `all` on filters that accept it. `all` equals an omitted filter.

## Read the capability matrix

[`GET /api/v1/platforms`](/api-reference/endpoint/get-platforms) is public and needs no API key. Read it at runtime instead of a hard-coded table.

```bash
curl "https://api.0xinsider.com/api/v1/platforms"
```

| Capability | Polymarket | Kalshi |
|---|---|---|
| `grade` | `supported` | `unsupported` |
| `pnl` | `supported` | `partial` |
| `strategy` | `supported` | `unsupported` |
| `timeline` | `supported` | `partial` |
| `whale_signal` | `supported` | `unsupported` |
| `insider_radar` | `supported` | `unsupported` |
| `market_snapshot` | `supported` | `partial` |

- `supported` means every field of the surface is available.
- `partial` means some fields are absent. A Kalshi market snapshot serves `last_price` only, with no top of book.
- `unsupported` means the surface does not apply. Grades, P&L, strategy, and timelines come from a Polymarket-only pipeline.
- The matrix is static backend metadata. The endpoint does not call a provider at request time.

## Know the Polymarket-only endpoints

These endpoints read Polymarket data only. A Kalshi filter or id returns an empty list, never a fabricated row.

- [`/markets/explore`](/api-reference/endpoint/explore-markets). The `platform` parameter accepts `polymarket` only.
- [`/large-positions`](/api-reference/endpoint/list-large-positions). The scanner filters `platform = 'polymarket'`.
- [`/positions`](/api-reference/endpoint/get-positions). The `platform` field stays in the shape for a later Kalshi mirror.
- [`/leaderboard/trending`](/api-reference/endpoint/list-trending-wallets). Ranks come from the Polymarket leaderboard.
- [`/sports-edge-signals`](/api-reference/endpoint/get-sports-edge-signals) and [`/sports-edge-observations`](/api-reference/endpoint/get-sports-edge-observations).

## Read Kalshi rows on shared endpoints

These endpoints return rows from both platforms:

- [`/whale-trades/history`](/api-reference/endpoint/get-whale-trades-history) accepts `platform=polymarket`, `kalshi`, or `all`.
- [`/markets/sharp-money-flows`](/api-reference/endpoint/sharp-money-flows) accepts the same values. The default is `all`.
- [`/market/{condition_id}/intel`](/api-reference/endpoint/get-market-intel), [`/market/{condition_id}/snapshot`](/api-reference/endpoint/get-market-snapshot), and [`/markets/search`](/api-reference/endpoint/search-markets) return `market.platform`.

On a Kalshi row:

- `token_id` is `null`. Kalshi has no CLOB token.
- A whale trade keeps its provider outcome label in `outcome`.
- Trader fields such as `grade` can be `null` or absent.

Do not infer a fact from a `null`. With `expand=trust`, [trust metadata](/concepts/trust-metadata) marks an absent Kalshi value as `unavailable`.
