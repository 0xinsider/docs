Find trades with unusual timing, size, or wallet age, then add context before you act. A flag is a lead, not proof.

Every request needs a Pro API key. See [Authentication](/authentication). Insider radar is Polymarket only; see [Platforms](/concepts/platforms).

## 1. Pull suspicious live trades

[`GET /api/v1/whale-trades`](/api-reference/endpoint/get-whale-trades) carries the live suspicion score on each trade.

- `suspicious_only=true` keeps rows with `suspicion_score` of 60 or more.
- `suspicion_score` is 0 to 100. It is null when no score is stored.
- `suspicion_track` names the scorer track: `whale`, `fresh_conviction`, or `sliced_position`.
- `whale` is a large trade backed by a fresh wallet, conviction, or a cluster.
- `fresh_conviction` is a new wallet with a lopsided contrarian bet below the whale size gate.
- `sliced_position` is one wallet that splits a large position into many small fills in a short window.

```python
import os

import requests

BASE = "https://api.0xinsider.com/api/v1"
H = {"Authorization": f"Bearer {os.environ['OXINSIDER_API_KEY']}"}

trades = requests.get(
    f"{BASE}/whale-trades",
    params={"suspicious_only": "true", "limit": 50},
    headers=H,
    timeout=30,
).json()

for tr in trades["data"]:
    who = tr["trader"]["username"] or tr["trader"]["address"][:10]
    print(
        tr["suspicion_score"], tr["suspicion_track"], who, tr["side"],
        tr["outcome"], tr["size_usd"], tr["market"]["title"],
    )
```

## 2. Pull the radar flags

[`GET /api/v1/insider-radar`](/api-reference/endpoint/get-insider-radar) lists stored flags with their component scores.

- `severity` is `flag` or `watch`. `flag` is the higher tier.
- `min_suspicion` is 0 to 100. The list is highest suspicion first.
- `scores` has `timing`, `edge`, `size`, and `fresh_wallet`. Each is nullable.
- `evidence` is the structured detection detail.
- [`GET /api/v1/insider-radar/{id}`](/api-reference/endpoint/get-insider-radar-flag) returns one flag by its `rf_` ID.

```python
flags = requests.get(
    f"{BASE}/insider-radar",
    params={"severity": "flag", "min_suspicion": 70, "limit": 50},
    headers=H,
    timeout=30,
).json()

for f in flags["data"]:
    s = f["scores"]
    who = f["trader"]["username"] or f["trader"]["address"][:10]
    print(
        f["id"], f["suspicion_score"], who, f["market"]["title"],
        "timing", s["timing"], "edge", s["edge"], "size", s["size"], "fresh", s["fresh_wallet"],
    )
```

## 3. Add context

Read the wallet and the market before you act on a lead.

- [`GET /api/v1/trader/{address}`](/api-reference/endpoint/get-trader) returns `grade`, `stats.markets_traded`, and `sync_status`. An unknown wallet returns `sync_status: "unknown"`, not `404`.
- [`GET /api/v1/market/{condition_id}/intel`](/api-reference/endpoint/get-market-intel) returns `sharp_money.net_flow_usd` and `sharp_money.direction` for the timeframe.
- `smart_money` is a deprecated alias of `sharp_money`. Read `sharp_money`.
- Compare the flagged `side` and `outcome` with `sharp_money.direction`.

```python
flag = flags["data"][0]
addr = flag["trader"]["address"]
cond = flag["market"]["condition_id"]

trader = requests.get(f"{BASE}/trader/{addr}", headers=H, timeout=30).json()["data"]
intel = requests.get(
    f"{BASE}/market/{cond}/intel", params={"timeframe": "24h"}, headers=H, timeout=30
).json()["data"]

print("grade:", trader["grade"], "markets:", trader["stats"]["markets_traded"], trader["sync_status"])
print(
    "sharp money:", intel["sharp_money"]["direction"],
    intel["sharp_money"]["net_flow_usd"], "over", intel["timeframe"],
)
```

## 4. Cross-check the position size

[`GET /api/v1/large-positions`](/api-reference/endpoint/list-large-positions) shows the open positions on one market.

- `condition_id` scopes the list to one market. `min_size` is in USD.
- `total_size_usd`, `share_count`, and `avg_entry_price` are nullable.
- `trader.grade` shows whether a graded wallet holds the same side.

```bash
curl -H "Authorization: Bearer $OXINSIDER_API_KEY" \
  "https://api.0xinsider.com/api/v1/large-positions?condition_id=0x123...&min_size=25000"
```

## 5. Get push alerts

Subscribe a webhook to `insider_radar_flag_raised`. It fires the first time a trade's suspicion score crosses the flag threshold.

- The event is Pro only.
- `data` carries `trade_id`, `wallet`, `trader_id`, `condition_id`, `suspicion_score`, `track`, `side`, `size`, and `price`.
- `track` uses the same three values as `suspicion_track`.

See [Webhooks](/guides/webhooks) for the setup and the signature check.

## Scope

- The positions board carries `trader.is_new_wallet` and `trader.wallet_age_days`, but has no `condition_id` filter.
- `is_new_wallet` means the first sighting was within 30 days. It is not the on-chain wallet age.
